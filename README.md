# Java Trainer

Десктоп-тренажёр по **Java Core → Spring Boot → Hibernate/JPA** — **69 практических заданий** в **13 темах** (по областям Java / Spring Boot / Hibernate / Проект; каждая тема — минимум 5 задач). Минимум теории, максимум практики: код пишется прямо в приложении, мгновенная проверка, подсказки и эталонные решения. Задачи — реальные рабочие сценарии (скидки, активные пользователи, выручка, статусы заказа, REST, сущности, репозитории).

**Реальный запуск Java.** Задания Java Core по-настоящему компилируются и запускаются через локальный JDK (кнопка «Запустить»): код проверяется не по шаблону, а по фактическому выводу программы. Если JDK не найден — остаётся проверка по критериям. Задания Spring/Hibernate проверяются по шаблонам (их нельзя собрать без библиотек фреймворка).

Построен на **Electron + React + Vite + Tailwind + shadcn/ui** (Radix UI), светлая тема, редактор кода — **CodeMirror 6** с подсветкой Java. Прогресс сохраняется автоматически.

Компоненты shadcn/ui лежат в `src/renderer/src/components/ui/` (Button, Card, Badge, Progress) — их можно править прямо в проекте или добавлять новые по гайду [ui.shadcn.com](https://ui.shadcn.com). Настройки в `components.json`, дизайн-токены — CSS-переменные в `src/renderer/src/index.css`.

## Запуск (разработка)

```bash
npm install      # один раз
npm run dev      # запустить приложение с hot-reload
```

## Сборка установщика

```bash
npm run package:win   # .exe (NSIS) для Windows
npm run package:mac   # .dmg для macOS (запускать на Mac)
```

Готовые установщики появятся в папке `release/`.

## Как пользоваться

1. Слева — модули и задания. Зелёная галочка = решено.
2. В каждом задании: краткая теория, формулировка задачи, редактор кода.
3. **«Запустить»** (для Java Core, если есть JDK) — реальная компиляция и сверка вывода.
   **«Проверить»** — разбор кода по критериям задания (работает всегда).
4. **Подсказки** открываются по одной. **«Показать решение»** подставляет эталон.
5. Прогресс и введённый код сохраняются между запусками.

Для реального запуска нужен установленный **JDK 11+** (`java`/`javac` в `PATH` или
переменная `JAVA_HOME`). Без него тренажёр полностью работает на проверке по критериям.

## Структура проекта

```
src/
  main/
    index.js           Electron main-процесс (окно, прогресс, IPC)
    java-runner.js     детект JDK + компиляция/запуск Java
  preload/             безопасный мост renderer ↔ main
  renderer/src/
    data/curriculum.js все задания (теория, заготовки, решения, проверки, run)
    lib/checker.js     проверка кода по шаблонам
    lib/javaRun.js     запуск задания через JDK и сверка вывода
    components/         UI: Sidebar, TaskView, CodeEditor, Markdown, ui/*
    App.jsx            сборка приложения и управление прогрессом
```

## Добавить своё задание

Открой `src/renderer/src/data/curriculum.js` и добавь объект в `tasks` нужного модуля:

```js
{
  id: 'jc-6',
  title: 'Название',
  difficulty: 'Лёгкое',         // Лёгкое | Среднее | Сложное
  theory: 'Краткая теория с **жирным** и `кодом`.',
  task: 'Что нужно сделать.',
  starter: `public class Main { }`,
  solution: `public class Main { }`,
  hints: ['Подсказка 1', 'Подсказка 2'],
  checks: [
    { type: 'contains', value: 'class Main', message: 'Объявлен класс Main' }
  ]
}
```

Типы проверок в `checks`: `contains`, `containsNorm` (без учёта пробелов), `notContains`,
`regex` (значение — строка регулярки), `minLength`.

Чтобы задание **реально запускалось** через JDK, добавь поле `run`:

```js
run: {
  expected: '15',        // ожидаемый вывод программы (сравнение по trim)
  // harness: `...`       // необязательно: доп. код с класса Main,
  //                      // если в задании пишется только класс/метод без main
  // entry: 'Main'        // класс с main (по умолчанию 'Main')
}
```

Подходит только для самодостаточного Java-кода (без Spring/Hibernate).

## Портирование на macOS

Код кросс-платформенный из коробки. На Mac: `npm install`, затем `npm run dev` или
`npm run package:mac`. Заголовок окна уже использует нативный стиль macOS (hiddenInset).

## Сборка .dmg для macOS

`.dmg` собирается **только на macOS** (electron-builder использует системный `hdiutil`).
На Mac:

```bash
npm install
npm run package:mac   # → release/Java Trainer-1.0.0.dmg
```

На Windows можно собрать только `.exe` (`npm run package:win`). Для .dmg без Mac —
GitHub Actions с `runs-on: macos-latest` (CI соберёт артефакт в облаке).
